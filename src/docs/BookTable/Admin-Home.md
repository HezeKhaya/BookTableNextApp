# BookTable Admin Documentation

Welcome to the BookTable Admin Guide. This documentation covers all core functionalities to help you manage orders, sales, stock, and users efficiently.

## Modules

- [[Admin-Capture-Orders|Capture Orders]]: Process new book orders and upload supplier invoices.
- [[Admin-Capture-Sales|Capture Sales]]: The Point of Sale system for recording cash and EFT sales, and managing pending payments.
- [[Admin-Record-Keeping|Record Keeping]]: Store supplier invoices and take stock snapshots.
- [[Admin-Stock|Stock Management]]: Update inventory quantities and manage the book catalog.
- [[Admin-Users|User Management]]: Administer staff access and roles.
