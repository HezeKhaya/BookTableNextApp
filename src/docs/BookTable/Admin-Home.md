# BookTable Admin Documentation

Welcome to the BookTable Admin Guide. This documentation covers all core functionalities to help you manage orders, sales, stock, and users efficiently.

## Modules

- [Capture Orders](/admin/docs/Admin-Capture-Orders): Process new book orders and upload supplier invoices.
- [Capture Sales](/admin/docs/Admin-Capture-Sales): The Point of Sale system for recording cash and EFT sales, and managing pending payments.
- [Record Keeping](/admin/docs/Admin-Record-Keeping): Store supplier invoices and take stock snapshots.
- [Stock Management](/admin/docs/Admin-Stock): Update inventory quantities and manage the book catalog.
- [User Management](/admin/docs/Admin-Users): Administer staff access and roles.
